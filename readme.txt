Rewrite media URLs to a remote WordPress uploads directory and optionally download files locally while visitors browse your site.

== Description ==

Remote Media Sync helps WordPress sites share the same database across several environments without having to duplicate a large `wp-content/uploads` directory.

The plugin can rewrite public attachment URLs generated by WordPress so that media files are loaded from another uploads base URL, such as a production media directory. It can also redirect direct public requests to local upload URLs when those requests reach WordPress.

This is useful for:

* Local development environments using a production database.
* Staging or pre-production sites without a full copy of the uploads directory.
* Large media libraries that are difficult to synchronize between environments.
* WordPress refactoring or redesign workflows where the database is shared but domains differ.

Example:

A local site may generate this media URL:

`https://local.example.test/wp-content/uploads/2026/05/image.jpg`

The plugin can rewrite it to:

`https://production.example.com/wp-content/uploads/2026/05/image.jpg`

== Features ==

* Rewrite attachment URLs generated by `wp_get_attachment_url()`.
* Rewrite responsive image URLs generated in `srcset` attributes.
* Redirect direct requests to `/wp-content/uploads/...` when WordPress receives the request.
* Configure the remote uploads URL from the WordPress admin.
* Override settings with environment constants in `wp-config.php`.
* Optional debug logging.
* No database tables.
* No front-end assets.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/remote-media-sync/` directory, or install the plugin through the WordPress plugins screen.
2. Activate the plugin through the Plugins screen in WordPress.
3. Go to Settings > Remote Media Sync.
4. Enable media URL rewriting and enter the remote uploads base URL.

== Configuration ==

The remote uploads base URL should point directly to the uploads directory of the environment that stores the media files.

Example:

`https://www.example.com/wp-content/uploads`

Do not include a trailing slash.

You can also define constants in `wp-config.php`:

`define( 'ABC_REDIRECT_MEDIA_UPLOADS_ENABLED', true );`

`define( 'ABC_REDIRECT_MEDIA_UPLOADS_BASE_URL', 'https://www.example.com/wp-content/uploads' );`

`define( 'ABC_REDIRECT_MEDIA_UPLOADS_DEBUG', false );`

Constants override saved options. This is recommended for environment-specific configuration.

== Frequently Asked Questions ==

= Does this copy media files? =

No. The plugin only rewrites or redirects URLs. The remote environment must already contain the media files.

= Does this work if Nginx or Apache returns a 404 before WordPress loads? =

The URL rewriting filters still work for URLs generated by WordPress. However, direct media redirects only work when the request reaches WordPress. If the web server handles the missing file before WordPress loads, server configuration may be required.

= Does this affect the admin media library? =

The plugin rewrites URLs generated through WordPress attachment URL functions. This can affect both front-end and admin contexts where those functions are used.

= Can I use a CDN URL? =

Yes. Any valid uploads-compatible base URL can be used, including a CDN URL, as long as the relative file paths match the WordPress uploads structure.

= Can I disable the plugin per environment? =

Yes. Either disable it from the settings page or define `ABC_REDIRECT_MEDIA_UPLOADS_ENABLED` as `false` in `wp-config.php`.
