Rewrite media URLs to a remote WordPress uploads directory and optionally download media files locally while visitors browse your site.

== Description ==

Remote Media Sync helps WordPress installations share the same database across multiple environments without requiring a full copy of the uploads directory.

The plugin can rewrite attachment URLs generated by WordPress so media files are loaded from a remote uploads directory, such as a production environment. It can also redirect direct media requests and progressively download media files locally as visitors browse your site.

This makes it possible to:

* Develop locally using a production database.
* Use staging or pre-production environments without copying large uploads directories.
* Gradually rebuild a local media library while users browse the site.
* Reduce deployment complexity for large WordPress installations.
* Migrate sites without immediately transferring thousands of media files.

Example:

A local site generates:

`https://local.example.test/wp-content/uploads/2026/05/image.jpg`

Remote Media Sync rewrites it to:

`https://production.example.com/wp-content/uploads/2026/05/image.jpg`

Optionally, when "Download while navigating" is enabled, the file can be downloaded automatically and stored locally the first time it is requested.

== Features ==

* Rewrite attachment URLs generated by WordPress.
* Rewrite responsive image URLs in srcset attributes.
* Redirect direct requests to media files through WordPress.
* Progressive media synchronization while visitors browse the site.
* Automatic local caching of remote media files.
* Configure remote uploads URLs from the WordPress administration panel.
* Exclude specific media URLs from rewriting and synchronization.
* Environment-specific configuration through wp-config.php constants.
* Optional debug logging.
* No custom database tables.
* No front-end assets.
* Works with shared WordPress databases across environments.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/remote-media-sync/` directory or install the plugin through the WordPress Plugins screen.
2. Activate the plugin through the Plugins screen.
3. Navigate to Settings → Remote Media Sync.
4. Enable media URL rewriting.
5. Enter the remote uploads base URL.
6. Optionally enable "Download while navigating" to progressively synchronize media files locally.

== Configuration ==

The remote uploads base URL should point directly to the uploads directory of the environment containing the media files.

Example:

`https://www.example.com/wp-content/uploads`

Do not include a trailing slash.

You may also configure the plugin using constants in `wp-config.php`:

`define( 'REMOTE_MEDIA_SYNC_ENABLED', true );`

`define( 'REMOTE_MEDIA_SYNC_BASE_URL', 'https://www.example.com/wp-content/uploads' );`

`define( 'REMOTE_MEDIA_SYNC_DOWNLOAD_WHILE_NAVIGATING', true );`

`define( 'REMOTE_MEDIA_SYNC_DEBUG', false );`

Constants take precedence over saved settings.

== Frequently Asked Questions ==

= Does this copy media files? =

By default, no. The plugin rewrites URLs and redirects requests to a remote uploads directory.

If "Download while navigating" is enabled, media files can be progressively downloaded and stored locally as visitors access them.

= Does this work with very large media libraries? =

Yes. The plugin was designed for environments where synchronizing the entire uploads directory would be impractical.

The optional progressive download feature allows media files to be synchronized only when they are actually needed.

= Does this work if Nginx or Apache returns a 404 before WordPress loads? =

URL rewriting still works because URLs are generated by WordPress.

Direct media redirects only work if the request reaches WordPress. If your web server intercepts missing files before WordPress loads, additional server configuration may be required.

= Can I use a CDN URL? =

Yes. Any URL compatible with the WordPress uploads structure can be used, including CDN endpoints.

= Can I disable the plugin on specific environments? =

Yes. You can disable it from the settings page or define:

`define( 'REMOTE_MEDIA_SYNC_ENABLED', false );`

in `wp-config.php`.

= Why are media files not downloading locally? =

Some servers, CDNs, or security services may block automated downloads, hotlinking, or server-to-server requests. In these situations media URL rewriting will still work, but automatic local synchronization may not.
